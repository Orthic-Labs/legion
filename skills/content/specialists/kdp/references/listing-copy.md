# Listing Copy

Use for Amazon KDP title/subtitle, description, keywords, categories, A+ content, and Etsy listing copy.

## Amazon KDP Principles

Amazon says the book description is often a reader's first experience with the content and recommends descriptions be simple, compelling, and professional. Do that. Do not stuff keywords into prose.

## Field Limits

- Title + subtitle together: 200 characters or fewer.
- Description: 4000 characters or fewer.
- Keywords: 7 slots. Keep each slot within the current KDP UI limit, commonly 50 characters; verify at upload.
- Categories: 3.
- No HTML in title, subtitle, author/contributor, or keyword fields.

## Title / Subtitle

- Put the actual buyer/search promise in plain English.
- Avoid claims that exceed the book.
- Avoid stuffing every keyword into the title.
- For kids books, include age if it naturally helps.
- Keep series identity stable.

## Description

Structure:

1. One sentence that names the buyer and promise.
2. Short paragraph on what is inside.
3. Bullet list of tangible contents.
4. Why it is different.
5. Soft close.

Use HTML supported by KDP only when preparing the upload block.

## Keywords

KDP provides 7 keyword slots. Use phrases buyers would search, not isolated vague terms. Cover:

- topic/entity
- format
- audience/age
- use occasion
- cultural/festival term
- activity type
- long-tail buyer intent

Avoid repeating exact title words in every slot if better long-tail phrases exist.

## Categories

Pick 3 accurate categories where the buyer actually shops. Relevance beats vanity. If no perfect category exists, use keywords to help Amazon shelve the book.

## A+ Content

Use A+ to show interior quality, especially for coloring/activity books. Include:

- interior preview
- series map
- age/use case
- what makes the book culturally careful
- proof that pages are not repetitive filler

Do not add claims not supported by the book.
