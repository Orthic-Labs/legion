# Workflows

## Brainstorm A KDP Book

1. Name audience, moment, problem, and gift/use case.
2. Generate 5-10 differentiated concepts.
3. Reject generic/low-originality concepts: no AI slop, recycled prompts, pet portraits, repost content, vague journals, or books Adrian cannot credibly improve.
4. Pick 1-3 to validate.
5. Create `PRODUCT-VALIDATION.md` before production.

## Build A Kids Mythology Guide

1. Validate market and format.
2. Write story spine and lesson promises.
3. Draft 32-page map.
4. Write reader pages.
5. Write production notes: sources, accuracy choices, open decisions.
6. Review with `manuscript-and-art-qa.md`.
7. Lock reader text.
8. Generate art against locked specs.
9. Build PDF and cover.
10. Run print QA and order proof.

## Review A Manuscript

1. Read reader file.
2. Read production notes.
3. If relevant, read source roadmap/creative brief.
4. Run mechanical checks.
5. Run story/voice/cultural checks.
6. Run placeholder/art brief checks.
7. Run KDP risk checks.
8. Produce verdict with blockers first.

## Create Listing Copy

1. Read validation memo and manuscript.
2. Extract real promise and contents.
3. Draft Amazon description in simple, compelling, professional prose.
4. Draft 7 keyword slots.
5. Draft 3 categories.
6. Draft A+ content modules.
7. Flag any claims that need proof or policy check.

## Production QA

1. Confirm final page count, trim, bleed/no-bleed, paper, and ink choice.
2. Confirm the intended reading model before layout: text-over-art, text page + art inset, or story page facing a full-page coloring page. For story + coloring books, do not shrink coloring art into story pages or put story text on top of coloring areas unless Adrian explicitly approves that format.
3. Run the interior image actuals gate: count, uniform dimensions, effective 300 DPI, RGB/flattened mode, safe margins, trim-edge artifacts, spread pairing, and page-by-page brief diff.
4. Assemble the interior PDF only after image actuals pass. Then check page size, margins/gutter, fonts, line weights, placeholder text, crop marks, and local PDF rendering.
5. Build the cover separately as one exterior full wrap: back + spine + front. Use KDP's cover template/calculator after the final page count is locked.
6. Confirm no spine text under KDP's spine-text threshold, and keep the back-cover barcode area clear when using KDP auto-barcode.
7. Resolve color guidance. For B&W interiors, do not add color reference pages unless Adrian deliberately accepts color-interior pricing; prefer back-cover thumbnails, A+ content, and/or a B&W reader note.
8. Confirm title/subtitle/author match the cover, metadata, and listing.
9. Confirm AI disclosure path.
10. Inspect KDP Print Previewer manually.
11. Order proof copy before going live.

## Production Verdict Ladder

Use the narrowest true verdict:

1. **Manuscript ready for render:** reader text, production notes, art briefs, and open decisions are clean.
2. **Interior images PDF-layout ready:** final images pass the image actuals gate but the PDF may not exist yet.
3. **Interior PDF upload-ready:** assembled PDF passes KDP interior checks.
4. **Cover upload-ready:** full wrap cover passes sizing, barcode, spine, and metadata checks.
5. **KDP-ready:** interior PDF, cover PDF, listing/metadata, AI disclosure, and proof-preview plan are all complete.
