# Carousel capture

Use `tools/pipelines/transcribe/carousel.py` to extract existing Instagram carousel slides. This is
a local tool, not social strategy or carousel copywriting.

1. Freeze source URL & output directory.
2. Read `docs/rules/execution-preflight.md` before batch, remote, or credentialed execution.
3. Run tool help or smallest dry-run/smoke path first.
4. Preserve source order & original resolution.
5. Return output paths plus failed-slide evidence.

Route carousel concept, copy, slide structure, or platform optimization to `social`; route new
visual asset production to `designer`.
