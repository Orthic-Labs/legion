# YouTube

## Always start with
1. `/brand <brand-code>` — voice + visual
2. **Identify task:** new video / clone existing / channel strategy / thumbnail+title / Shorts series

This package plans and writes YouTube content: structure, beat timing, titles, thumbnail concepts, and the script's prose (via `writing`). Video and audio production, and transcription, are not part of this package. If the host provides a `media-production` capability, use it for production; otherwise deliver the plan as text and say production was skipped.

## Task workflows

### New video script
1. Confirm: topic, target length (Short <60s, mid 5-8min, long 12-20min), and the brand card's tone and pace.
2. Hook research: use the 5 top-performing videos in the niche that the user names or provides (titles, first-15-second notes, or a transcript the user pastes). If the host provides `web-search`, you may look them up. Do not invent view or retention numbers.
3. Pick an angle that contradicts or complements (not duplicates) what is working.
4. Draft the beat structure: hook (3s) → promise (10s) → tease (20s) → 3-act payoff → CTA.
5. Hand the spoken script prose to `writing`; keep the beats and timing here.
6. Visual plan: a shot list per beat, as text. If the host provides `media-production`, hand the shot list to it.
7. Read-aloud test on the script.
8. Output: script + shot list + B-roll list + thumbnail concepts (3)

### Clone a high-performer
1. Get the transcript or notes from the user. This package does not transcribe video. If the host provides a transcription capability (none is declared here), use it; otherwise ask the user to paste the transcript.
2. Extract structure: hook type, beat timing, payoff cadence, retention triggers.
3. Analyze the thumbnail the user supplies: focal point, contrast, face, text count.
4. Analyze the title: structure (curiosity gap / number / how-to / tease).
5. Output a CLONE BRIEF: structure to copy, with the user's topic substituted in.
6. Generate a brand-aligned script from that structure (steps 4-7 of New video script).

### Channel strategy
- Long-form: deep dives on the brand's core subject, at the length the brand card sets.
- Shorts: single-moment clips and answers to one common question each.
- Match the format mix to the brand card's pillars. Take tone, pace, and music per brand from the card's video section.

### Thumbnail + title testing
1. Generate 3 title variants (specific number / curiosity gap / contrarian)
2. Generate 3 thumbnail concepts → `/designer static`
3. A/B test plan: which to test first, what to measure, decision rule

## Hook patterns
- "I [unusual thing] for [time period]. Here's what happened."
- "Everyone says [common belief]. They're wrong because..."
- "This [product] costs [N]× more than [alternative]. Here's why."
- "[Number] mistakes I made [doing X]"
- Open mid-action

## Anti-patterns
- "Hey guys what's up" intros
- Asking for likes/subs in first 30s
- Pacing for radio (no visuals = no retention)
- Treating Shorts as cropped longs

## Brand video defaults
Take tone, pace, and music per brand from the brand card's video section. Do not copy one brand's defaults to another brand.
