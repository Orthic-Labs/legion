# YouTube

## Always start with
1. `/brand <brand-code>` — voice + visual
2. **Identify task:** new video / clone existing / channel strategy / thumbnail+title / Shorts series

## Task workflows

### New video script
1. Confirm: topic, target length (Short <60s, mid 5-8min, long 12-20min)
2. Hook research — find 5 top-performing videos in this niche, transcribe their first 15s
3. Pick angle that contradicts/complements (not duplicates) what's working
4. Script via killer-scripter pattern: hook (3s) → promise (10s) → tease (20s) → 3-act payoff → CTA
5. Visual plan via visual-storyteller — shot list per beat
6. Read aloud test
7. Output: script + shot list + B-roll list + thumbnail concepts (3)

### Clone a high-performer
1. URL → /transcribe
2. Extract structure: hook type, beat timing, payoff cadence, retention triggers
3. Pull thumbnail, analyze: focal point, contrast, face, text count
4. Pull title, analyze: structure (curiosity gap / number / how-to / tease)
5. Output a CLONE BRIEF: structure to copy + your topic substituted in
6. Generate brand-aligned script using that structure

### Channel strategy
- DD: long-form product/craft deep dives (10-15min) + Shorts of single-product detail moments
- RH: educational textile/ethics content (8-12min) + Shorts addressing fast-fashion myths
- SS: BTS portrait sessions (5-8min) + Shorts of photo reveals/before-after

### Thumbnail + title testing
1. Generate 3 title variants (specific number / curiosity gap / contrarian)
2. Generate 3 thumbnail concepts → /marketing-design
3. A/B test plan: which to test first, what to measure, decision rule

## Hook patterns
- "I [unusual thing] for [time period]. Here's what happened."
- "Everyone says [common belief]. They're wrong because..."
- "This [product] costs [N]× more than [alternative]. Here's why."
- "[Number] mistakes I made [doing X]"
- Open mid-action

## Anti-patterns
- "Hey guys what's up" intros
- Asking for likes/subs in first 30s
- Pacing for radio (no visuals = no retention)
- Treating Shorts as cropped longs

## Brand video defaults
| Brand | Tone | Pace | Music |
|---|---|---|---|
| DD | Considered, low-key, tactile | Slow zooms, long shots | Ambient |
| RH | Documentary, honest | Medium, lots of cuts to detail | Acoustic |
| SS | First-person, contemplative | Slow, deliberate | Sparse / silent |
