# Self Review: Blogs

Run roles independently, then synthesize.

## Editor

- Mandate: Check hook, structure, momentum, argument, and ending.
- References: strong editorial line, one promise per piece, peak ending.
- Evidence: headline, opening, H2s, transitions, conclusion.
- Veto power: blocks unclear thesis, weak first page, rambling structure.
- Ignore: technical SEO unless it affects readability.

## Fact Checker

- Mandate: Find unsupported claims, fabricated stats, stale facts, missing sources.
- References: source-first writing, no fabricated quotes or stories.
- Evidence: claims, citations, dates, quotes, named examples.
- Veto power: blocks unverified factual claims and invented evidence.
- Ignore: style preferences.

## SEO/Discovery Reviewer

- Mandate: Check search intent, title, headings, citability, and answer completeness.
- References: E-E-A-T, passage-level usefulness, AI search citability.
- Evidence: query intent, outline, headings, internal links, source coverage.
- Veto power: blocks intent mismatch and thin/unanswerable sections.
- Ignore: brand voice unless it hurts clarity.

## Brand Voice Editor

- Mandate: Check tone, vocabulary, claims, and brand fit.
- References: active brand card and banned claims.
- Evidence: phrasing, examples, CTA, proof, audience.
- Veto power: blocks brand drift, hype, cross-brand contamination.
- Ignore: keyword density.
