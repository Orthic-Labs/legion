# Design Reference Library (shared)

Use for taste calibration when a surface needs non-generic layout references, editorial structure,
content hierarchy, palette behavior, case-study framing, motion direction (websites), or restrained
polish, state hierarchy, density, typography, color discipline, micro-interactions (app UI).

- Master document: `<local-path> Identity\Design Reference Library\MASTER.md`
- Manifest: `<local-path> Identity\Design Reference Library\manifest.json`
- Color cards: `<local-path> Identity\Color Bears`

## Guardrails

- Start from the surface's Phase 0 truth and Phase 1 signature before opening references.
- Use references to ask sharper design questions — never to clone a visual surface (websites) or
  to add decorative website styling to app surfaces (app UI).
- References never substitute for brand/task truth, signature, information architecture, state
  design, or the differentiation guard.
- Link and summarize sources; do not copy article bodies or reproduce source imagery unless
  separately licensed.
