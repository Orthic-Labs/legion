# Illustration Direction

Direct illustration as a communication problem, not a decoration problem. This guide owns the method; the consuming project's brand context owns the visual style. Never prescribe a medium, palette, or house style here.

## Load

1. Take the communication objective from the request: what must a viewer understand without reading copy?
2. Load the consuming project's brand or style contract for medium, palette, typography, and negatives. If none exists, ask for one or state the style assumption explicitly before generating.
3. Apply `../../../_shared/parametric-design.md` for variant spread and `../../../_shared/anti-slop.md` to any copy produced alongside the artwork.

## Method

1. **Objective.** State the single idea the image carries, in one sentence.
2. **Role.** Decide what the illustration does: explain a mechanism, set a mood, mark a section, carry an identity, or replace a screenshot. The role bounds every later choice.
3. **Representation strategy.** Choose literal depiction, diagrammatic abstraction, metaphor, or scene. Prefer the most literal option that carries the idea; metaphor is a cost, not a default.
4. **Composition.** Fix one dominant focal point, one reading direction, and one secondary beat. Reserve copy space deliberately; keep generated typography out of the frame unless requested.
5. **Semantic roles.** Give every visible object one clause of purpose. Delete anything unexplainable.
6. **Parameterize.** Name the axes that actually change meaning — subject, strategy, composition, density, accent placement, risk — and vary those, never cosmetic swaps.
7. **Diverge.** Produce at least three concepts on named axes for non-trivial work; one production candidate for settled, repeat work.
8. **Critique.** Run a separate critic pass on semantic legibility first, craft second. Iterate one variable at a time.
9. **Select and finish.** Save approved work inside the consuming project; never leave a deliverable only in a generator cache.

## Acceptance gate

Approve only when every answer is yes:

- Can a viewer state the idea without reading copy?
- Does every visible object have a purpose?
- Is the reading order unambiguous?
- Does the image satisfy the consuming project's own style contract, including its negatives?
- Does it avoid the generic default look for its category?
- Are locked brand assets — logos, wordmarks, icon packs, tokens — reproduced unchanged or left out?
