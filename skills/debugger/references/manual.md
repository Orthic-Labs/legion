# Debugger route manual

Canonical method lives in [`../../../doctrine/bundles/sage-diagnose.md`](../../../doctrine/bundles/sage-diagnose.md)
and [`../../../doctrine/sage.md`](../../../doctrine/sage.md). This compatibility artifact exists so
legacy entrypoint consumers retain a stable manual path.

Read `../../../agents/sage.md` first. Debugger is Sage's Diagnose route: establish a reproducible or
bounded oracle, isolate evidence, test disconfirmable hypotheses, prove cause, then freeze a handoff.
It never performs product-source effects; hand settled effects to Alchemist. Reversible incident
containment may precede diagnosis only when explicitly labelled containment.
