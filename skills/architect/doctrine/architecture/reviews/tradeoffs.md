# Trade-off review

Use only after credible alternatives pass mandatory gates. Inputs: frozen drivers, scenarios, failure stories, lifecycle costs, evidence grades, & residual-risk authorities. Outputs: dominance record, sensitivity result, selected or deferred outcome, & durable rejection reasons.

Do not use to compare cosmetic vendor substitutions, revive eliminated options, or score an option before hard-gate failure is resolved. Eliminate dominated options before weighted comparison; evidence-starved orderings become `PARETO_SET_PENDING_EVIDENCE`, never another opinion round.
