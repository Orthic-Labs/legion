# Rubric: priority

**Framing.** Portfolio-aware. Default REVISE (defer) unless this work clearly out-scores the other work competing for the same attention. Native verdicts: DO-NOW, DEFER, DROP.
**Input required.** The packet must describe both the work under consideration and the competing work and constraints it displaces. The portfolio comes only from the packet; do not assume one. Without it, return INSUFFICIENT_EVIDENCE.
**Frames.** Theory of Constraints (where is the real bottleneck?); output metrics, not activity; leverage (does it create a compounding asset?); cognitive bias (am I picking the shiny thing?); opportunity cost.

**Dimensions (1-10).** expected_revenue_impact, opportunity_cost, compounding_asset_creation, bottleneck_relief, downside_containment, time_to_signal, attention_efficiency, irreversibility_risk

**Forced questions.**
- what_else_drops: if this is done, which other work this week is dropped or delayed? Name it.
- bottleneck_match: does this attack the actual constraint (sales, supply, cash, team, judgment) or a non-constraint?
- compounding_asset: does this build an asset that pays again next month, or is it one-shot output?
- time_to_signal: how soon do we know if it is working (days, weeks, months)?
- shiny_object_check: what would a friend who does not share the enthusiasm say about why this is really being done?
- missing_evidence: what would you need that is not in the packet?

**Fail modes.** shiny_new_thing_without_distribution, attacks_non_constraint, attention_arbitrage_against_self, one_shot_output_no_compounding, slow_signal_with_low_reversibility, judgment_spread_thin, irreversible_with_low_signal, defending_sunk_cost, peer_pressure_fomo, copying_someone_elses_priority
