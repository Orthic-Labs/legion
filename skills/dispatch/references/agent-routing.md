# Dispatch routing

Use Dispatch for bounded executor delegation. Ordinary workers stay ambient. Attach Sage only for material unresolved meaning or ownership that routine capability mandates cannot settle; use Alchemist for controlled contracts & Oracle for requested or risk-justified independent review. Fresh-session continuity uses Handoff. Dispatcher retains integration ownership; worker write scopes do not overlap, while reads may overlap.

## Subagent models

Every `Agent`/`Task` launch names a model or takes the default: the `mechanical-cheap` tier, never above `balanced-executor`. Model names live only in the `subagents` block and tiers of `src/config/model-tiers.json`; `legion-hook` enforces the ceiling from that file, filling in the default when a generic launch names no model. Sage and Oracle (`frontier-judgment`) resolve to the ceiling and need no marker. A model above the ceiling is only for one the operator named in the live turn: the launch prompt then carries the line `operator-approved-model: <model>` naming that one model. When a launch is refused, read the reason and relaunch within the ceiling or ask the operator; never add the marker on your own judgement.
