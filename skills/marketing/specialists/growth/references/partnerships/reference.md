# Partnerships and Borrowed Audiences

Use this when the user wants growth through someone else's audience, credibility, distribution, or listing surface.

## Partnership Fit

Score each partner:

| Factor | Question |
|---|---|
| Audience overlap | Do they reach the same buyer or adjacent buyer? |
| Offer fit | Does the collaboration solve a real problem for both audiences? |
| Trust transfer | Would their endorsement reduce doubt? |
| Distribution power | Email list, community, traffic, social reach, event attendance |
| Operational ease | Can both sides ship without heavy coordination? |

Avoid vanity partnerships where the audience is large but wrong.

## Co-Marketing Plays

| Play | Best for | Output |
|---|---|---|
| Webinar/workshop | Education and lead capture | shared landing page, email swaps, replay clips |
| Newsletter swap | Fast audience testing | 2 blurbs, UTM links, follow-up offer |
| Joint guide/template | SEO and authority | co-branded asset, nurture sequence |
| Integration launch | Product-led distribution | landing page, docs, demo, partner announcement |
| Podcast/YouTube guesting | Founder-led trust | topic map, talking points, CTA |
| Directory/listing layer | Discovery and backlinks | prioritized directory tracker |

## Directory Layer

Submit only after the destination page is ready:

- Clear value proposition and category
- Pricing or beta status
- Screenshots, logo, demo video if relevant
- FAQ and structured data plan
- Use-case or comparison pages for the link equity to support

## Output Format

Return:

1. Partner/listing priority table
2. Recommended play for each
3. Pitch angle
4. Asset checklist
5. Tracking plan: UTM, landing page, source, leads, conversion quality
6. First outreach message
