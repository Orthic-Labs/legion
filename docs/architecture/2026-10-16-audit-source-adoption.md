# Audit source adoption: exact gaps & acceptance

**Decision:** adoption is partial. Legion mechanisms overlap substantially with both designs: deterministic triage, risk-ranked sampling, excerpt bundles, promotion, schema/ID/duplicate checks, dismissal sampling, resumable `next`, diff narrowing, security multi-stage adjudication, JSON/SARIF/Markdown/HTML outputs, & a seeded benchmark. That overlap does not establish imported provenance. Preserve existing behavior while absorbing correctness guarantees below. A clean-looking report must never hide missing candidates, unread evidence, failed required providers, or an unverified dismissal.

This compares Legion HEAD `d2c754bbfaa7da79b9700b1f03a0ebd2ccf5553e` with pinned OpenQodex `736fd1484a05ead753375f52232bcf9e70f84246` & Alibaba Open Code Review `11ac6d4c57082f310067a4a1654ad5b63cb57410`. Upstream links below resolve to those commits. I read implementation, prompts, & relevant tests; did not run upstream code or tests. Existing context: [prior source brief](2026-10-15-audit-research/alibaba-openqodex.md) and [Audit v2 design](2026-10-15-audit-v2-design.md). The design describes intended scope/cache/graph behavior; it is not evidence that every design item ships.

## P0: preserve candidate identity, location, & applicability

Legion's p11d candidate constructor records `file` & `line`, but the security adjudicator derives path & line only from `evidence[0]`; generic `.set` detection is not Redis-specific. Legacy binary pinning treats any URL lacking same-line `sha256`, `integrity`, or `@` as a high finding. These make provenance and context errors plausible: evidence may be discarded between scanner and adjudication, generic code may be mislabeled, & a documentation URL can be called an unpinned executable. See [p11d candidate construction](../../engine/crates/legion-audit/src/native_providers/p11d_quality/mod.rs#L68), [candidate evidence ingestion](../../engine/crates/legion-audit/src/native_providers/reasoning/security_adjudication.rs#L674), [p11d patterns](../../engine/crates/legion-audit/src/native_providers/p11d_quality/mod.rs#L164), & [legacy URL check](../../engine/crates/legion-audit/src/native_providers/legacy_checks/mod.rs#L2743).

Absorb OpenQodex's SARIF normalization & loss ledger, plus Alibaba's per-file rule binding and deterministic rule precedence: [SARIF path/location normalization](https://github.com/openqodex/openqodex/blob/736fd1484a05ead753375f52232bcf9e70f84246/packages/scanners/src/formats/sarif.ts#L42), [scanner candidate disposition trail](https://github.com/openqodex/openqodex/blob/736fd1484a05ead753375f52232bcf9e70f84246/packages/scanners/src/run.ts#L322), [rule precedence](https://github.com/alibaba/open-code-review/blob/11ac6d4c57082f310067a4a1654ad5b63cb57410/internal/config/rules/system_rules.go#L444), & [per-file binding](https://github.com/alibaba/open-code-review/blob/11ac6d4c57082f310067a4a1654ad5b63cb57410/internal/agent/agent.go#L1686). Canonical candidate records should retain source/provider/rule, normalized path, line/range (or explicit unknown), evidence digest, applicability language × receiver/library, & every later disposition. Unknown location remains unresolved; never silently drop it. Keep secret redaction and secret-specific safe evidence.

**Acceptance:** a Redis session/ephemeral key without required TTL is positive, while same key with valid TTL is negative; durable Redis key policy is explicit; JavaScript `Map.set` & config setters are negative; executable download without immutable hash raises while docs URL does not; all adapters preserve file/range or explicit unknown; mixed-language bundle selects correct rule pack; every generated candidate has exactly one disposition.

## P0: bind denominator, lens coverage, & actual delivery

OpenQodex checks delivered ranges—including removed code—and tests those rules: [completion validator](https://github.com/openqodex/openqodex/blob/736fd1484a05ead753375f52232bcf9e70f84246/packages/core/src/completion.ts#L79), [range coverage](https://github.com/openqodex/openqodex/blob/736fd1484a05ead753375f52232bcf9e70f84246/packages/core/src/completion.ts#L199), [tests](https://github.com/openqodex/openqodex/blob/736fd1484a05ead753375f52232bcf9e70f84246/packages/core/src/completion.test.ts#L219).

Legion's excerpt selection precedes trigger evaluation, and `examinedPaths` proves packet inclusion, not that a seat received/read the packet. A release lens can be issued with an empty review set; several lens triggers can disagree with selection. Promotion currently lets one too-large unpromoted candidate block later affordable candidates. See [selection/trigger order](../../engine/crates/legion-audit/src/native_providers/reasoning/mod.rs#L623), [packet coverage](../../engine/crates/legion-audit/src/native_providers/reasoning/mod.rs#L1188), [promotion loop](../../engine/crates/legion-audit/src/native_providers/reasoning/mod.rs#L1055), & [trigger evidence construction](../../engine/crates/legion-audit/src/native_providers/reasoning/mod.rs#L664).

Freeze trigger witness & applicable denominator before sampling; bind every applicable lens to delivered evidence or explicit incomplete/unavailable reason. Count only bytes actually delivered in a model request; tool replies generated but never sent do not count. Any remaining required range is an explicit gap. Declared risk-sampling exclusions remain exclusions, not automatic incompleteness. Preserve unknown scanner output distinct from empty. OpenQodex itself does **not** make scanner failure change exit status, so copy its candidate accounting, not that policy. Its five read-only server tools are bounded/redacted with 32 KB replies, but host subprocess adapters add different capabilities; treat them separately ([tool index](https://github.com/openqodex/openqodex/blob/736fd1484a05ead753375f52232bcf9e70f84246/packages/review/src/tools/index.ts#L1)).

**Acceptance:** every frozen denominator item/lens has exactly one terminal state; no duplicate or omitted assignment; missing required provider or seat receipt yields incomplete; tests cover added, removed, empty, multi-chunk, failed, partially returned, & concurrently issued evidence; a declared risk-sampled exclusion stays excluded; selected/mandatory unread evidence is a gap; an unaffordable promotion does not starve a later affordable item in priority order.

## P0: candidate accounting & end-to-end budget

OpenQodex finalization accounts for each live candidate passed through scanner filtering, requiring it to be raised or dropped exactly once; the scanner-run ledger separately records kept, merged, disabled-rule, fixture, and outside-change stages, while raw findings need their own ledger: [finalizer](https://github.com/openqodex/openqodex/blob/736fd1484a05ead753375f52232bcf9e70f84246/packages/core/src/finalize.ts#L493), [loss ledger](https://github.com/openqodex/openqodex/blob/736fd1484a05ead753375f52232bcf9e70f84246/packages/scanners/src/run.ts#L322). Legion has candidate dedup/schema checks and seeded dismissal sampling. Cluster risk is concrete: normalized excerpts lowercase code and can fall back to a generic message, while the key omits provider/path/line/context, then expands one representative across members ([normalization](../../engine/crates/legion-audit/src/native_providers/reasoning/security_adjudication.rs#L1750), [cluster key](../../engine/crates/legion-audit/src/native_providers/reasoning/security_adjudication.rs#L1873), [representative expansion](../../engine/crates/legion-audit/src/native_providers/reasoning/security_adjudication.rs#L1427)). Built-in vendor/generated exclusions are active; only host-supplied `excluded_paths` & `resolved_fingerprints` sets default empty ([triage inputs](../../engine/crates/legion-audit/src/native_providers/reasoning/mod.rs#L789), [reasoned exclusions](../../engine/crates/legion-audit/src/native_providers/reasoning/security_adjudication.rs#L1805)). Preserve each original raised, dismissed, unresolved, merged, & suppressed candidate; require evidence-backed semantic equivalence before merge, and reason/evidence for each dismissal.

One queue currently mixes candidate domains: reasoning aggregates every candidate-generator into security adjudication ([generator aggregation](../../engine/crates/legion-audit/src/native_providers/reasoning/mod.rs#L1617)). Preserve rule/category & route data, reliability, release, and security findings to applicable authority and evidence contracts; otherwise weak applicability or severity can trigger costly security follow-ups.

Legion's budget is not one enforced runtime limit: `next` has a 2,000-token stage estimate, allows absent budget, then expects a top-level `reasoningBudget`; ingest writes run limits under `limits.*` instead ([stage estimate](../../engine/crates/legion-audit/src/next.rs#L76), [absence allowed](../../engine/crates/legion-audit/src/next.rs#L290), [budget read](../../engine/crates/legion-audit/src/next.rs#L604), [run limits written](../../engine/crates/legion-audit/src/native_providers/reasoning/ingest.rs#L3014)). Alibaba offers useful rendered-prompt preflight, full tool-round compression, and actual-attempt observation: [agent prompt check](https://github.com/alibaba/open-code-review/blob/11ac6d4c57082f310067a4a1654ad5b63cb57410/internal/agent/agent.go#L1325), [tool-round compression](https://github.com/alibaba/open-code-review/blob/11ac6d4c57082f310067a4a1654ad5b63cb57410/internal/llmloop/compression.go#L19), [attempt observer](https://github.com/alibaba/open-code-review/blob/11ac6d4c57082f310067a4a1654ad5b63cb57410/internal/llm/retry_observer.go#L23).

Persist one budget across all seats, retries, reflection, & tools; reserve before concurrent work, reconcile actual input/output/cache tokens afterward, and include full prompt/schema/workspace/tool overhead. Separate estimates from actuals and cached from uncached use. No soft overspend, grace completion, or unsupported savings claim.

**Acceptance:** missing budget fails visibly; resume and concurrent seats cannot authorize beyond remaining reservation budget; rendered prompt/tool payloads are charged; ledger separates planned, reserved, actual input/output/cache, retries, and failures; each candidate has one evidenced final disposition; JSON, SARIF, Markdown, and HTML agree on gaps, confidence, provenance, and status. The existing renderers are [here](../../engine/crates/legion-report/src/lib.rs#L14); SARIF is emitted from [Audit](../../engine/bins/legion/src/commands/audit.rs#L676).

Budgeting also needs shared payloads: current bundles estimate excerpt reads once, yet per-lens packets repeat excerpts/contracts/schema. Deliver common evidence once by reference plus compact lens instructions, and measure actual consumption ([packet byte basis](../../engine/crates/legion-audit/src/native_providers/reasoning/ingest.rs#L2996)). When a host budget is supplied, OpenQodex authorizes each rendered request before transport using messages, tools, output cap, and prior calls; refusal or budget exhaustion blocks completion ([authorization](https://github.com/openqodex/openqodex/blob/736fd1484a05ead753375f52232bcf9e70f84246/packages/review/src/model-loop.ts#L135), [refusal completion](https://github.com/openqodex/openqodex/blob/736fd1484a05ead753375f52232bcf9e70f84246/packages/core/src/completion.ts#L237)). Persist partial findings on exhaustion with `budget-exhausted`/incomplete; do not spend extra correction/retry calls or widen scope. Missing provider usage is `unknown`, not zero. Authorization reserves estimated usage; if reported physical usage exceeds it, emit actual overrun evidence instead of claiming a hard physical bound.

## Do not copy; implementation order

Do not copy OpenQodex's whole-repo completion exemptions for unread work, default fixture drops, scanner soft failures, optional second-failure completion, or 20-word style correction limit. Do not copy Alibaba's scan path that omits manifest scans, soft budget/grace behavior, proofless finding-ID removals, task-done as semantic inspection, or secret filtering as a universal tool boundary. No blanket fixture suppression, global four-lens cap, or mandatory fail-open scanner policy.

Sequence work: (1) canonical finding/location/applicability & per-candidate loss ledger; (2) frozen denominator, trigger-to-delivery receipts, truthful incomplete state; (3) enforced end-to-end budget plus full-pipeline benchmark; (4) immutable scope and tool/reflection boundary; (5) evidence-backed lens gap fill; (6) optional graph/cache. Review/ponytail projections & behavioral qualification remain deferred design work. Each phase exits only when its acceptance checks pass on fixtures and benchmark outputs. This report records source assessment, acceptance criteria, and the dated implementation state below.
