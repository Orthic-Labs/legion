8. **Quantified escalation basis**: risk-proportional routing flags with recorded rationale, and a reliability-vs-cost table for dispatch patterns to ground "verification proportional to blast radius." Sources: SWE-AF `needs_deeper_qa`/`risk_rationale`; NeoLab benchmarked pattern table.

## Alchemist

3. **Ledger-based recovery for multi-task contracts**: a per-run progress ledger recording completions and "Ruling:" decisions; on compaction trust git log + ledger over memory (the documented expensive failure is re-dispatching completed work). Source: obra subagent-driven-development.
4. **Tiered fix-loop with a hard adjudication cap**: rounds 1-3 same implementer, 4-5 fresh implementer on a stronger model, then mandatory adjudication of every open finding — a principled generalization of bounded retries. Source: obra.
5. **Independent re-validation + one-approval-per-fix + single consolidated commit** when applying externally sourced suggestions — never bulk-apply. Source: coderabbit autofix.
6. **Typed budget struct + circuit breakers**: step/cost/wall-time/max-consecutive-same-class-failure with `BUDGET_STOP` as a computed predicate; two-tier soft (recoverable autosubmit) vs hard (propagate) cost limits; a declared do-not-retry exception allowlist. Sources: compshop §17; swe-agent models.py; mini-swe-agent retry.
7. **Cost-routing decision criteria**: model-selection-by-complexity table plus the "turn count beats token price" finding; per-role flat model map with precedence. Sources: obra; SWE-AF role→model config; addyosmani per-persona tiering.
8. **Symptom-keyed repair lookup tables** ("search this file for the exact error text" → cause/trigger/fix) for the mechanical-repair mandate. Source: testdino error-index/common-pitfalls format.
9. **Bounded-transformation policy checklists**: the hard-cut compatibility ladder (no shims/fallbacks/dual-shape unless concrete external-boundary evidence) and typed exception → bounded-recovery state machine (every failure class routes to exactly one outcome). Sources: instructa hard-cut; swe-agent forward_with_handling.
10. **Wire the orphaned assurance**: put `skills/alchemist/tests/test_windows_runner.py` and the eval fixtures into CI (own audit finding), and adopt behavioral graders ("dispatches-the-workflow", "invokes-the-skill") to *measure* Alchemist trigger failure instead of inferring it. Source: trailofbits eval harness.

## Oracle

1. **Machine-checkable PASS/BLOCK receipt**: a typed verdict artifact digest-bound to the exact diff/artifact set reviewed — the missing piece behind "no false clean." Sources: own audit gap; gstack hash-chained content-free receipts; SWE-AF `oracleAudit` attestation block.
2. **Stop-time enforcement**: a Stop hook that blocks "done" without a fresh Oracle receipt; the bounded self-referential loop with an exact completion-promise string and max-iterations ceiling is a working reference. Sources: anthropics ralph-wiggum; NeoLab trigger-word Stop-hook (`decision: "block"` + cycle detection).
3. **Anchor-relative rubrics**: meta-judge writes a task-specific rubric before review with concrete score-2/score-4 anchor excerpts per dimension; reasoning-before-score; anti-sycophancy/anti-length-bias tables. Makes verdicts reproducible and leniency-resistant. Source: NeoLab judge/meta-judge.
4. **Fixed gate checklist for verdicts**: convert holistic PASS/BLOCK into named gates matching the blocking criteria (scope fidelity / regression / data loss / safety), each with an explicit PASS/FAIL line — auditable and comparable across runs. Source: trailofbits fp-check six-gate rubric.
5. **Independent per-finding validation before reporting**: every candidate BLOCK finding re-checked by a separate validator; uncertain findings dropped ("false positives erode trust"). Source: anthropics code-review pipeline.
6. **Coverage integrity rules**: recompute the inspected-scope inventory from ground truth (never the reviewer's own account), and a zero-item check must fail — plus Legion's own unlanded "empty-record-is-BLOCK" rule. Sources: trailofbits c-review ledger; compshop Part VI.3.
7. **Requirement-split validation**: one fresh validator per requirement on multi-requirement deliveries, each with its own evidence — inline checking degrades past the first few items. Source: compshop §23.
8. **Non-author refutation on demand**, including of PASS verdicts — a refutation that actually tries to break the verification. Source: compshop.
9. **Structural read-only enforcement**: a `tools:` allowlist on `agents/oracle.md` (no Bash/Edit/Write) — "the tool scope is the control; a prompt instruction is not one." Source: trailofbits c-review workers.
10. **Verdict economics + evidence discipline**: budget-isolated reviewer with cheap-filter-then-expensive-judge staging; full-SHA permalink citation format for durable findings; authority-pressure eval corpus asserting the completion gate fires under "skip the formalities" pressure. Sources: swe-agent reviewer.py; anthropics code-review; compshop.

## Arcane

Sources: gstack `SKILL_START_PROTO`; agentfield harness doctor.
7. **Hook-enforced loop and cycle bounds**: consecutive-invocation counters and max-iteration ceilings enforced at the hook level rather than prose ("no unbounded execution" as code). Sources: compshop mechanical cycle guard; anthropics ralph-wiggum.
8. **Layered declarative action blocklist + per-tool receipt declarations**: prefix/exact/allow-unless-regex tiers enforced inline before every action; each tool bundle self-declares its `state_command` so receipt coverage is structural per author. Source: swe-agent.
9. **Crash-proof observability primitives**: save-receipt-in-`finally` (gaps structurally impossible), typed exit-status exception hierarchy, and pre-flight limit checks with typed breach exceptions. Source: mini-swe-agent.
10. **Skill-level trust-boundary declarations**: require every packaged skill to carry an explicit "Security Trust Boundary" section (what's authorized, what's untrusted, redaction rules) that Arcane can audit for presence — defense-in-depth above the hook. Sources: testdino; coderabbit untrusted-input contract.

Sources: coderabbit DISTRIBUTION_CHANNELS.md; EricGrill manifest schema.

10. **Authoring hygiene**: shared reference files instead of duplicated procedural content; progressive disclosure (<150-word always-loaded text); the no-op pruning test ("an instruction the model already obeys pays load to say nothing"); doctrine-mass ratchet (doctrine LOC vs engine LOC across releases). Sources: LambdaTest shared/; obra; mattpocock; compshop Part X #11.
