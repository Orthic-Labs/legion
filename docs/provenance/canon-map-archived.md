## Stage 1 authority rules

- One row per concept, one `source_owner` per row, & one active source path set per active concept.
- Generated files are consumers only. Edit `AGENTS.md` and `docs/agent-rules.md` directly.
- Historical routing recorded in superseded architecture drafts is non-authoritative.
- Superseded bundle notes preserve provenance only; live routing uses Oracle.
- Runtime retry control stops on second identical fingerprint; accepted non-patch design invalidations increment the persisted revision counter automatically.
- A planned row becomes active only through its declared adoption stage with existing source paths, real producers/consumers, & fresh checks.
