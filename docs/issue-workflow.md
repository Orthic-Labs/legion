# Issue workflow

- Search the open issues before you file a new one, and put `Checked: #<n>[, #<n>...] (search "<terms>")` (or `Checked: none found (search "<terms>")`) in the body of every `gh issue create`. Give every create exactly one `--label` from `pipeline`, `decision`, `incident`, `bug`, `request`; a `decision` issue also needs a `Contract: <doc> <clause>` line and the boxes `- [ ] written-in-contract`, `- [ ] enforced-in-code (path:line)` and `- [ ] verified-by-run (receipt)`. Legion's hook no longer checks either rule.
- Close a contract only after its `decision` issues are closed and each decision is written into the contract; `legion run close` refuses a complete close while an open `decision` issue carries a `Contract: <contract id>` line (`engine/bins/legion/src/commands/run.rs`, `ARC_DECISION_ISSUES_OPEN`; `--disposition archive` is not refused).
