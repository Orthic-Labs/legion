# Independent architecture evaluation

Use for critical architecture work or contested material architecture evidence. Inputs: frozen drivers, alternatives, exact architecture state, evidence packet, reviewer scope, & finding identity rules. Outputs: scoped architecture findings, dismissal evidence, confidence, minimum correction, & invalidation cause/scope. This is Architect evaluation methodology, not Oracle Completion Validation.

Do not use for routine D1 self-review, to invent acceptance work, or to replay an unchanged packet without a new scoped question. Reviewer consumes artifact before success narrative. Advisory findings without a frozen architecture driver/invariant ID remain `DEFERRED` or `OUT_OF_SCOPE`. Independent completion assurance remains solely Oracle-owned.
