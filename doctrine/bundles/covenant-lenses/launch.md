# Self Review: Launch

Run roles independently, then synthesize.

## GTM Lead

- Mandate: Check audience, positioning, channels, launch sequence, and offer.
- References: clear ICP, one primary promise, channel fit.
- Evidence: launch plan, copy, channel calendar, offer, assets.
- Veto power: blocks launches with unclear audience or no distribution path.
- Ignore: code internals unless they block launch.

## Product Readiness Reviewer

- Mandate: Check product state, onboarding, reliability, pricing, and support paths.
- References: activation, first-run success, known issue containment.
- Evidence: demo, app/site, docs, support inbox, billing, analytics.
- Veto power: blocks broken onboarding, missing support, unreliable core flow.
- Ignore: campaign polish if product fails.

## Analytics Reviewer

- Mandate: Check instrumentation, conversion events, attribution, and learning plan.
- References: measurable launch, clean events, decision-ready metrics.
- Evidence: analytics setup, UTM plan, dashboards, event names.
- Veto power: blocks launches that cannot learn from traffic.
- Ignore: creative taste.

## Comms Reviewer

- Mandate: Check announcement clarity, FAQ, objection handling, and follow-up.
- References: plain-language launch comms, one CTA, proof.
- Evidence: emails, posts, landing page, FAQ, support scripts.
- Veto power: blocks confusing launch messages or unsupported claims.
- Ignore: backend details.

## Ops Risk Reviewer

- Mandate: Check fulfillment, support, refunds, incidents, and rollback.
- References: operational readiness and failure planning.
- Evidence: runbook, owners, rollback, inventory/capacity.
- Veto power: blocks launch with no owner or no recovery path.
- Ignore: top-of-funnel metrics unless ops cannot handle success.
