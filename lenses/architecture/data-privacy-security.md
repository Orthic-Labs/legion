# Data, privacy & security lens

**Applicability:** data authority, sensitivity, residency, retention, trust boundary, or attacker-controlled input is material. **Inputs:** data classification, owner, flow, threat model, constraints, & acceptance/invariant IDs. **Outputs:** authority/flow assessment, required controls, residual risk, & evidence plan. **Negative scope:** no unscoped security sweep, legal conclusion, or severity claim before dismissal gates.
